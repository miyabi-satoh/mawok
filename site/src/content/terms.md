この利用規約（以下「本規約」）は、Mawok（以下「本ソフトウェア」）と、AI アクションのクレジットを購入し、本ソフトウェアの AI アクションで使うためのアカウントのサービス（以下「アカウントのサービス」）の利用条件を定めるものです。
本ソフトウェアをインストールもしくは利用した時点、またはアカウントのサービスにサインインした時点で、本規約に同意したものとみなします。
運営者の情報とお問い合わせ先は、[運営者について](https://amiiby.com/about/)をご覧ください。

## 第1条（利用料金と AI アクションのクレジット）

1. 本ソフトウェアは無料で利用できます。AI アクションには、利用者の API キーで使う AI サービスの利用料か、次項のクレジットが要ります。
2. AI サービスに「Mawok」を選ぶと、利用者の API キーを使わず、アカウントの AI アクションのクレジット（以下「クレジット」）で AI アクションを使えます。クレジットは、使った量に応じて減ります。
3. クレジットに有効期限はありません。
4. 新しいアカウントには、試すためのクレジットを、運営者が定める量だけ一度付けます。その月に付けた量が運営者の定める上限に達したときは、翌月以降に付けます。運営者は、これらの量を変え、または付けるのをやめることがあります。

## 第2条（クレジットの購入）

1. クレジットは、アカウントのサービスで、購入の画面に表示する価格（税込み）で購入できます。決済は Stripe, Inc.（以下「Stripe」）を通じて行い、カードの情報は運営者が扱いません（[プライバシーポリシー](/privacy/)参照）。日本の外からの購入（接続元が日本と分からないときを含みます。以下同じ）は、Sold through Link, LLC（以下「Link」）が運営者の代理として販売と決済を行い、Link の[利用規約](https://link.com/terms)のうち「Link 経由の販売規約」も適用されます。
2. 購入したクレジットは、購入したアカウントに付きます。
3. デジタル商品の性質上、利用者の都合による購入後の返金・キャンセルはできません。運営者が二重に請求したとき、または決済の処理を誤ったときは、その分を返金します。運営者の責めによって、購入したクレジットが付かなかったとき、またはクレジットの記録が失われたときも、その分を返金します。Link を通じた購入は、購入から60日以内は Link の返金ポリシーが優先し、Link が返金することがあります。
4. 返金したとき、または不審な請求として決済の取り消しを申し立てられたときは、その購入で付けたクレジットのうち、残っている分を取り消します。
5. 購入に関するその他の表示は、[料金](/pricing/#conditions)の「購入の条件」と、amiiby の[特定商取引法に基づく表記](https://amiiby.com/tokushoho/)のとおりです。

## 第3条（アカウント）

1. アカウントのサービスには、メールアドレスに届くリンクか、Google または Apple のアカウントでサインインします。
2. 利用者は、自分が使えるメールアドレスでサインインしてください。
3. アカウントとアカウントに付いたクレジットを、他人に譲ったり、貸したりすることはできません。
4. アカウントの削除は、問い合わせで受け付けます。アカウントを削除すると、残っているクレジットも消え、返金はできません。
5. 利用者が本規約に反したときは、運営者は、アカウントを止め、または削除することがあります。この場合、残っているクレジットは返金しません。

## 第4条（利用の範囲）

1. 利用者は、本ソフトウェアを、自ら管理するパソコンにインストールして利用できます。台数に制限はありません。
2. 利用者が属する教室・事務所・家庭などの中で、本ソフトウェアを複数のパソコンに入れて使うことができます。

## 第5条（入手と再配布）

1. 本ソフトウェアは、運営者が公式に案内する場所から入手してください。
2. 次の行為は禁止します。

   - 本ソフトウェアを改変したもの、またはその一部を配布すること。

## 第8条（AI サービスの利用）

1. 本ソフトウェアのアクションのうち、行頭が `@ai` のものは、利用者が選んだ AI サービスに、テキストウィンドウに書いた文（以下「テキスト」）の内容と指示文を送ります。AI サービスは既定では使わない設定で、利用者が設定で選び、送る内容と扱いを了解したときにだけ使えます。
2. AI サービスに「Mawok」を選んだときは、アカウントのサービスが、テキストの内容と指示文を Google の Gemini API に取り次ぎ、クレジットを使います。使うモデルと、一度に送れる長さは、運営者が決めます。
3. Gemini・Anthropic・OpenAI を選んだときは、利用者が自ら用意した API キーを使います。AI サービスの利用料金と、そのサービスの規約の遵守は、利用者の責任です。
4. AI サービスに送った内容の扱いは、そのサービスの定めに従います。送った内容が、そのサービスの改善のために使われたり、一定期間保持されたりすることがあります。詳しくは[プライバシーポリシー](/privacy/)と、利用者が使うサービスの規約をご覧ください。
5. 運営者は、AI が返す内容の正確さ・適切さ・特定の目的への適合を保証しません。アクションの結果は、利用者が確認したうえで使ってください。
6. 他人の秘密や個人情報を含む文を送らないでください。送るかどうかの判断は、利用者の責任で行ってください。

## 第9条（コマンドの実行）

1. 本ソフトウェアのアクションは、利用者が登録した行や、その場で入力した行を、行頭が `@ai` のもの（第8条（AI サービスの利用））を除き、利用者の権限でコマンドとして実行し、テキストの内容をそのコマンドに渡します。
2. 実行するコマンドの内容と、その結果（ファイルの変更や削除、外部への送信などを含みます）は、利用者の責任です。内容を確かめてから実行してください。
3. コマンドがテキストの内容を外部へ送る場合、送った内容の扱いは、送り先の定めに従います。送り先の規約と扱いは、利用者が確認してください。
