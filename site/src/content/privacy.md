このプライバシーポリシーは、Mawok（以下「本ソフトウェア」）と、AI アクションのクレジットを購入し、本ソフトウェアの AI アクションで使うためのアカウントのサービス（以下「アカウントのサービス」）での情報の扱いについての、運営者の考え方を示すものです。

## 基本の考え方

- 本ソフトウェアが扱う情報は、利用者のパソコンの中にだけ置きます。テキストウィンドウに書いた文（以下「テキスト」）を外へ送るのは、利用者が自分で選んで設定した機能を、利用者が操作したときだけです。
- 運営者が預かるのは、アカウントのサービスで AI アクションのクレジットを購入し、使うための情報だけです。AI アクションで送ったテキストと結果は、運営者のサーバーに残しません。
- 何を残し、いつ消すかは、利用者が決められるようにします。

## 運営者と問い合わせ先

運営者の情報とお問い合わせ先は、[運営者について](https://amiiby.com/about/)をご覧ください。運営者の住所は、請求があれば遅滞なくお知らせします。
お問い合わせで受け取る情報の扱いは、amiiby.com の[プライバシーポリシー](https://amiiby.com/privacy/)によります。

## 本ソフトウェアが手元に置く情報

本ソフトウェアが動くために必要な情報（設定・テキストの履歴・AI サービスの API キー・アカウントのサービスのサインインの印など）は、利用者のパソコンの中にだけ置きます。
これらは、本ソフトウェアの機能を動かすためにだけ使い、運営者は預かりません。

利用状況・端末の情報などを、運営者に送ることはありません。例外は、Mac 版の更新の確認（→「本ソフトウェアの外部への送信」）と、本ソフトウェアでアカウントにサインインするときに送るコンピューターの名前です（アカウントのサービスの画面で、登録したパソコンを見分けるため）。入力した内容が運営者のサーバーを通るのは、AI サービスに「Mawok」を選んで AI アクションを実行したときだけです（→「AI アクションの取り次ぎ」）。不具合の自動送信も行いません。本ソフトウェアには、広告や、アクセス解析のための仕組みも入っていません。

## 本ソフトウェアの外部への送信

本ソフトウェアから外へ送るのは、次のときだけです。

- **AI サービスを使うアクション**: AI サービスは既定では使いません。利用者が AI サービスを選び、送る内容と扱いに同意したときにだけ、行頭が `@ai` のアクションを実行すると、その指示文とテキストを送ります。
  - AI サービスに「Mawok」を選んだときは、アカウントのサービスを通して、Google LLC の Gemini API へ送ります（→「AI アクションの取り次ぎ」）。
  - Gemini・Anthropic・OpenAI を選んだときは、利用者の API キーで、その AI サービスへ直接送ります。運営者のサーバーは通らず、送った内容の扱いは、利用者とその AI サービスとの間の規約によります。学習に使われるか、どれだけ保持されるかは、サービスや契約によって異なります。使う前に、その AI サービスの規約をご確認ください。
- **アカウントのサービスとのやり取り**: AI サービスに「Mawok」を選んだときだけ、サインイン・クレジットの確認（設定の「アクション」を開いたとき）・サインアウトのために、アカウントのサービスと通信します。テキストは送りません。アカウントのサービスには、通常のアクセスと同じく、パソコンのアドレスが伝わります。
- **利用者が設定したコマンド**: コマンドのアクションは、テキストを、利用者が登録した、またはその場で入力したコマンドに渡します。本ソフトウェア自身はそこで通信しませんが、コマンドがテキストを外へ送るかどうかは、そのコマンドによります。送り先の規約と扱いは、利用者がご確認ください。
- **機器の間の送信**: 利用者が組み合わせた自分の機器の間でだけ、同じネットワークの中でテキストを送ります。機器を組み合わせるときと、組み合わせた後に互いを見つけるために、コンピューターの名前や鍵の情報を同じネットワークの中に流します。これらにテキストは含みません。
- **Mac 版の更新の確認**: Mac 版は、起動して少ししてからと、その後は1日ごとに、新しい版があるかを運営者のサーバー（mawok.amiiby.com）に確かめます。送るのは、通常のアクセスと同じく伝わるパソコンのアドレスと、更新に使う部品の名前と版だけです。テキストや本ソフトウェアの設定は送りません。新しい版は、利用者が更新を選んだときにだけダウンロードします。

## 使う目的

- AI アクションのクレジットの購入と、本ソフトウェアの AI アクションで使うため
- サインインと本人の確認のため（サインインのリンクのメールの送信を含みます）
- 消費税の申告で、国内の売上と分けて数えるため
- 不正な利用を防ぎ、障害を調べるため（リンクの送信や申し込みの回数の制限など）
- 問い合わせに答えるため

これ以外の目的には使いません。広告には使いません。

## AI アクションの取り次ぎ

AI サービスに「Mawok」を選んで AI アクションを実行すると、アカウントのサービスが、指示文とテキストを Google LLC の Gemini API に送り、結果を本ソフトウェアに返します。

- 運営者は、送られたテキスト・指示文と結果を、保存しません。取り次ぐ間だけ、サーバーのメモリに一時的に置きます。残すのは、日時と使った量だけです。
- 運営者は Gemini API を有料の条件で使っており、Google は送った内容と結果を、自社の製品の改善に使いません。ただし Google は、禁止された使い方を見つけるためと法令に従うために、送った内容と結果を限られた期間記録します。
- 他人の秘密や個人情報を含む文を送らないでください（[利用規約](/terms/)の第8条（AI サービスの利用））。

## AI アクションのクレジットの購入

AI アクションのクレジットを購入するとき、決済は Stripe, Inc.（以下「Stripe」）が提供する決済ページ（Stripe Checkout）で行います。

- カード番号などの決済情報は Stripe が直接受け取り、運営者は取得・保存しません。
- 決済ページには、アカウントのメールアドレスをあらかじめ入力した状態で移ります。Apple の転送用のメールアドレスのアカウントでは、決済ページでメールアドレスを入力していただきます。
- Stripe から運営者へは、決済が完了したかどうかと、購入した商品・金額、返金・不審な請求の申し立ての有無が通知されます。運営者はこれをもとに、アカウントにクレジットを付け、または取り消します。
- 日本の外からの購入（接続元が日本と分からないときを含みます。以下同じ）は、Sold through Link, LLC（以下「Link」）が運営者の代理として販売と決済を行います。決済ページで入力する氏名・住所・決済情報は、Stripe と Link が、税の計算・領収書の発行・返金などのために、それぞれ自らの方針（[Link のプライバシーポリシー](https://link.com/privacy)）で扱います。運営者が記録するのは、上の通知の内容と、Link を通じた購入かどうか・カードの発行国・購入したときの接続元の国・国内の購入かどうか（決済ページで入力した住所の国などから判断します。消費税の申告で、国内の売上と分けるため）だけです。決済の内容を確かめるために Stripe から取り寄せる情報に氏名・住所が含まれることがありますが、記録しません。

## 第三者への提供

次のいずれかに当たるときを除き、本人の同意なく個人情報を第三者に提供しません。

- 法令に基づくとき
- 人の生命・身体・財産を守るために必要で、本人の同意を得ることが難しいとき
- 「アメリカ合衆国にある事業者への委託」のとおり、個人データの取り扱いを委託するとき
- 事業の承継に伴って個人情報が移るとき

## 保存する期間

- 本ソフトウェアの情報は、利用者のパソコンの中にあり、利用者が管理し、利用者が消します。テキストの履歴は、設定から、いつでも消せます。本ソフトウェアを消したときに、ほかの情報が一緒に消えるかどうかは、入れ方によって違います。残った情報は、OS の機能で消せます。
- アカウントのサービスのメールアドレス・クレジット・購入の記録は、アカウントの削除を求められるまで保存します。クレジットに期限が無いためです。使われないアカウントを、運営者が自動で消すことはありません。
- アカウントを削除したあとも、購入の記録のうち決済の識別子・商品・金額と通貨・日時・Link を通じた購入かどうか・国内の購入かどうか・返金や不審な請求の申し立ての有無と、使った記録は、アカウントと切り離して7年保存します。帳簿と請求書の写しを保存し、消費税を申告し、削除のあとに届く返金や不審な請求の申し立てに対応するためです。メールアドレスなど人を特定できる情報と、カードの発行国・接続元の国は残しません。
- サインインの状態（30日）・サインインのリンク・パソコンを登録する申し込みは、期限が切れたあと、その後の利用に合わせて消します。本ソフトウェアに渡したサインインの印は、本ソフトウェアでサインアウトするか、アカウントのサービスの画面で登録を解除するまで使えます。

## 安全管理のための措置

- 基本方針: 個人情報を正しく扱うため、このポリシーを定め、必要に応じて見直します。
- 組織的な措置: アカウントのサービスの個人情報を扱えるのは運営者だけです。
- 人的な措置: 運営者は、個人情報を目的の外に使わず、漏らしません。
- 物理的な措置: データは、入退室が管理されたデータセンターに保存します。運営者の手元の端末には保存しません。
- 技術的な措置:
  - アカウントのサービスとの通信はすべて暗号化します（HTTPS）。
  - パスワードは持ちません。サインインのリンク・サインインの状態・本ソフトウェアに渡したサインインの印は、元に戻せない形で保存します。
  - サインインのリンクの送信や申し込みの回数を制限します。
  - 本ソフトウェアは、AI サービスの API キーとアカウントのサービスのサインインの印を、OS の資格情報管理に置きます。機器の間で送るテキストは、暗号化します。テキストの履歴は、暗号化せずに残ります。パソコンの管理は、利用者が行ってください（[利用規約](/terms/)の第10条（利用者の責任））。
- 外的環境の把握: 「アメリカ合衆国にある事業者への委託」の事業者に委託しています。アメリカ合衆国の個人情報の保護の制度を把握した上で、上の措置を講じています。

## 開示などの請求

利用者は、アカウントのサービスの自分の個人情報について、利用目的の通知・開示・訂正・追加・削除・利用の停止・消去・第三者への提供の停止、第三者への提供の記録の開示を求めることができます。

- 請求は、上の問い合わせ先からご連絡ください。アカウントのメールアドレスでのやり取りなどで、本人であることを確かめてから対応します。
- アカウントを削除すると、残っている AI アクションのクレジットと、Google・Apple でのサインインの設定、登録したパソコンの記録も消えます。
- 手数料はいただきません。

本ソフトウェアの情報は、運営者が持たないので、開示などの請求を受ける対象がありません。

## Cookie

アカウントのサービスでは、サインインの状態と、表示する言語を保つためだけに Cookie を使います。広告や、行動の分析のための Cookie は使いません。
