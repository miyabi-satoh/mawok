このプライバシーポリシーは、Mawok（以下「本ソフトウェア」）と、このサイト（mawok.amiiby.com）での情報の扱いについての、運営者の考え方を示すものです。

## 運営者と問い合わせ先

運営者の情報とお問い合わせ先は、[運営者について](https://amiiby.com/about/)をご覧ください。
お問い合わせで受け取る情報の扱いは、amiiby.com の[プライバシーポリシー](https://amiiby.com/privacy/)によります。

## 本ソフトウェアが扱う情報

本ソフトウェアは、設定と、テキストウィンドウに書いた文（以下「テキスト」）の履歴を、利用者のパソコンの中の設定の保存先（設定画面で選ぶフォルダー）に保存し、本ソフトウェアの機能を動かすためにだけ使います。運営者は、これらを受け取りません。

## 本ソフトウェアの外部への送信

本ソフトウェアは、利用状況・端末の情報・テキストや設定などを、運営者にも第三者にも送りません。不具合の自動送信も行わず、広告やアクセス解析の仕組みも入っていません。

例外は、Mac 版の更新だけです。どちらも、送るのは通信のときに伝わる IP アドレスなどだけで、テキストや設定は送りません。

- **更新の確認**: 起動したときと、その後1日ごとに、新しい版があるかを運営者のサイト（mawok.amiiby.com）に確かめます。
- **更新のダウンロード**: 利用者が更新を選んだときだけ、新しい版を GitHub, Inc. の GitHub Releases からダウンロードします。GitHub での扱いは、[GitHub のプライバシーに関する声明](https://docs.github.com/ja/site-policy/privacy-policies/github-general-privacy-statement)をご覧ください。

## 第三者への提供

運営者は、本ソフトウェアの利用者の情報を受け取らないので、第三者に提供することもありません。

## 保存と削除

テキストの履歴は、設定から、いつでも消せます。本ソフトウェアを消したときに、ほかの情報が一緒に消えるかどうかは、入れ方によって違います。残った情報は、OS の機能で消せます。

## 安全管理

テキストの履歴は、暗号化せずに、設定の保存先に残ります。

## 利用者の権利

本ソフトウェアの情報は、運営者が持たないので、開示などの請求を受ける対象がありません。ご質問は、上の問い合わせ先からご連絡ください。

## このサイトのアクセス解析

このサイト（mawok.amiiby.com）は、Cloudflare, Inc. のアクセス解析サービス「Cloudflare Web Analytics」を使います。
Cloudflare Web Analytics は、Cookie などのブラウザーに保存する仕組みを使わず、受け取った IP アドレスを記録に残さず、訪問者を個人として識別しません。集めた情報は、このサイトの利用状況を知り、改善するために使います。Cloudflare での扱いは、[Cloudflare のプライバシーポリシー](https://www.cloudflare.com/privacypolicy/)をご覧ください。

このサイトのページを表示すると、ブラウザーから次の事業者に情報が送られます（電気通信事業法の外部送信規律に基づく表示）。

- **Cloudflare Web Analytics**（このサイトのすべてのページ）
  - 送信先: Cloudflare, Inc.
  - 送られる情報: 閲覧したページの URL、IP アドレス、参照元、ページの表示にかかった時間、ブラウザーや端末の種類
  - 目的: このサイトの利用状況を知るため

## このポリシーの変更

運営者は、必要に応じてこのポリシーを変更することがあります。
変更後のポリシーは、このページに掲載した時点から効力を持ちます。
