# Mawok の使い方

## はじめに

どのアプリを使っているときでも、テキストウィンドウを出して書き、コピーして元のアプリに貼り付けられます。

::: linux
初めて起動したときにデスクトップがショートカットの追加を尋ねてきたら、追加します。尋ねてこないデスクトップ (Ubuntu 24.04 の GNOME や Hyprland など) では、先にデスクトップの設定でホットキーを割り当てます (「[ホットキーを割り当てる](#ホットキーを割り当てる)」を参照)。
:::

1. {macos:`Cmd+Shift+Space`}{windows:`Ctrl+Shift+Space`}{linux:`Ctrl+Shift+Space`} を押して、テキストウィンドウを出します。
2. 書きます。`Enter` は改行です。
3. {macos:`Cmd+Enter`}{windows:`Ctrl+Enter`}{linux:`Ctrl+Enter`} を押すと、コピーしてテキストウィンドウが閉じ、元のアプリに戻ります。そこで貼り付けます。

ほかに、定型文を挿入したり、前にコピーしたテキストを呼び戻したりできます。
Mawok は{macos:メニューバー}{windows:タスクトレイ}{linux:トレイ}に常駐し、ログイン時に起動します (設定の「一般」でオフにできます)。

::: linux
## ホットキーを割り当てる

設定の「キー操作」のホットキーの欄に `mawok --toggle` が出ているときは、デスクトップの設定で、このコマンドにキーを割り当てます。デスクトップが尋ねてきたショートカットの追加を取り消したときも同じです。

GNOME では、次のように割り当てます。

1. 「設定」の「キーボード」で、「ショートカットの表示とカスタマイズ」を押します。
2. 「カスタムショートカット」を選び、「ショートカットを追加」を押します。
3. 「名前」に `Mawok`、「コマンド」に `mawok --toggle` を入れます。
4. 「ショートカットを設定」を押して、`Ctrl+Shift+Space` など割り当てるキーを押し、「追加」を押します。

Hyprland では、設定ファイルにキーの割り当てを足します。`hyprland.lua` には、次の行を足します。

```lua
hl.bind("CTRL + SHIFT + SPACE", hl.dsp.exec_cmd("mawok --toggle"))
```

`hyprland.conf` を使っているときは、次の行を足します。

```
bind = CTRL SHIFT, SPACE, exec, mawok --toggle
```

ほかのデスクトップでも、キーボードの設定で `mawok --toggle` にキーを割り当てます。X11 のデスクトップでは、設定の「キー操作」のホットキーがそのまま効きます。
:::

## 書いてコピーする

- {macos:`Cmd+Enter`}{windows:`Ctrl+Enter`}{linux:`Ctrl+Enter`} を押すか「コピー」ボタンを押すと、コピーして元のアプリに戻ります。
- テキストウィンドウが前面にあるときにホットキーを押しても、コピーして戻ります。
- コピーせずに戻るときは `Esc` を押します。書きかけは、次にテキストウィンドウを出したときもそのまま残っています。
- ほかのアプリをクリックしたときも、コピーせずに隠れ、書きかけは残ります (設定の「一般」でオフにできます)。

## 前にコピーしたテキストを使う

コピーしたテキストは履歴に残ります。

- 入力欄の先頭で `↑` を押すと、前にコピーしたテキストが出ます。押すたびに古い方へさかのぼり、入力欄の末尾で `↓` を押すと新しい方へ戻ります。上の「前」「次」のボタンでも同じです。
- 残す件数は設定の「一般」で変えられます。0 にすると履歴を残しません。
- 履歴を同期しているときは、設定の「履歴を削除する」を押すか件数を 0 にすると、ほかのデバイスの履歴も消えます (「[設定の保存先を変える](#設定の保存先を変える)」を参照)。

## 定型文を使う

よく使う文を登録しておき、選んで挿入します。

1. {macos:`Cmd+K`}{windows:`Ctrl+K`}{linux:`Ctrl+K`} を押して、定型文の一覧を出します。
2. 文字を打って絞り込み、`Enter` で選びます。カーソルの位置に挿入されます。範囲を選んでいれば、その範囲と置き換わります。

定型文は設定の「定型文」で登録します。一覧の末尾の「テキストを定型文に登録」を選ぶと、書いているテキストをその場で登録することもできます。範囲を選んでいればその範囲を、絞り込みに文字を打っていればその文字を名前にして登録します。

## 設定の保存先を変える

設定と履歴は、設定の保存先のフォルダーにファイルで置きます。iCloud Drive・OneDrive・Dropbox などのクラウドストレージのフォルダーを保存先にすると、ほかのデバイスと同期できます。

1. 設定の「一般」の「設定の保存先」で「変更...」を押し、クラウドストレージの中のフォルダーを選びます。
2. ほかのデバイスでも、同じフォルダーを選びます。そのフォルダーの設定を使うかを聞かれたら、「このフォルダーの設定を使う」を押します。

書いたテキストの続きを別のデバイスで書くには、{macos:`Cmd+Enter`}{windows:`Ctrl+Enter`}{linux:`Ctrl+Enter`} でコピーして閉じ、別のデバイスのテキストウィンドウで `↑` を押して履歴を出します。届くまでの時間は、クラウドストレージによります。

- 同期するもの: 設定、キー操作、置き換え辞書、定型文、履歴。ホットキーとキー操作は、{macos:Mac どうし}{windows:Windows どうし}{linux:Linux どうし}で同じになります。
- デバイスごとのもの: ログイン時の起動と、選んだ保存先。
- 設定は `settings.toml`、定型文は `snippets.toml`、置き換え辞書は `replacements.toml` のテキストファイルです。テキストエディターで直すこともでき、保存するとすぐに反映されます。dotfiles の管理ツールで扱うこともできます。
- 履歴は、保存先の `history` フォルダーにデバイスごとのファイルで置きます。dotfiles を Git で管理するときは、`history` フォルダーを入れないようにします。

同じファイルを2台で同時に変えたときは、後から保存した方が残ります。前の設定に戻すには、バックアップから戻します (「[設定](#設定)」を参照)。

## キー操作の一覧

| 操作 | キー |
| --- | --- |
| テキストウィンドウを出す (前面にあればコピーして閉じる) | {macos:`Cmd+Shift+Space`}{windows:`Ctrl+Shift+Space`}{linux:`Ctrl+Shift+Space`} |
| コピーして閉じる | {macos:`Cmd+Enter`}{windows:`Ctrl+Enter`}{linux:`Ctrl+Enter`} |
| コピーせずに閉じる | `Esc` |
| 履歴をさかのぼる (入力欄の先頭で)・新しい方へ戻る (入力欄の末尾で) | `↑` / `↓` |
| 履歴をさかのぼる・新しい方へ戻る (カーソルの位置にかかわらず) | {macos:`Cmd+Option+↑` / `Cmd+Option+↓`}{windows:`Ctrl+Alt+↑` / `Ctrl+Alt+↓`}{linux:`Ctrl+Alt+↑` / `Ctrl+Alt+↓`} |
| 定型文の一覧を開く | {macos:`Cmd+K`}{windows:`Ctrl+K`}{linux:`Ctrl+K`} |
| 設定を開く | {macos:`Cmd+,`}{windows:`Ctrl+,`}{linux:`Ctrl+,`} |

キーは設定の「キー操作」で変えられます。

## 設定

{macos:メニューバー}{windows:タスクトレイ}{linux:トレイ}のメニューの「設定…」を選ぶか、テキストウィンドウで {macos:`Cmd+,`}{windows:`Ctrl+,`}{linux:`Ctrl+,`} を押すと開きます。
ホットキー、テキストの見た目、コピーするときの整え (末尾の空白を取る・全角と半角を揃える・置き換え辞書など) を変えられます。変えた内容はすぐに反映されます。
既定の値から変えた設定には、行の左端に縦の線が付きます。

設定は毎日、自動でバックアップされます。前の設定に戻すには、設定の「このアプリについて」で「バックアップから戻す...」を押し、戻したい日時を選んで「この設定に戻す」を押します。「今すぐバックアップ」を押すと、その時点の設定を残せます。

## うまくいかないとき

- **{macos:メニューバー}{windows:タスクトレイ}{linux:トレイ}のメニューに ⚠ が出る**: その項目を選ぶと設定が開き、問題のある行に理由が出ます。
- **ホットキーが効かない**: {macos:}{windows:}{linux:Mawok の設定で割り当てたときは、}ほかのアプリが同じキーを使っています。{macos:}{windows:このとき、メニューに「⚠ ホットキーを登録できません」が出ます。}{linux:このとき、メニューに「⚠ ホットキーを登録できません」が出ます。}設定の「キー操作」で別のキーにします。
::: linux
- **デスクトップの設定で割り当てたキーが効かない**: デスクトップのほかのショートカットが同じキーを使っています。別のキーにします。
- **テキストウィンドウを閉じても、元のアプリに戻らない**: 閉じた後にどのウィンドウに移るかは、デスクトップが決めます。元のアプリをクリックしてから貼り付けます。
- **トレイに Mawok のアイコンが出ない**: GNOME では、`gnome-extensions enable ubuntu-appindicators@ubuntu.com` を実行して、トレイを出す拡張機能をオンにします。Hyprland では、バー (waybar など) の設定にトレイを足します。
:::
- **「設定のファイル 〜 を読めません」と出る**: テキストエディターで直したときの書き間違いです。ログに、読めない行の番号が残っています。直して保存すると、すぐに読み直します。直せなければ、そのファイルを消すか、設定の「このアプリについて」で「バックアップから戻す...」を押して前の設定に戻します。
- **「〜 が見つかりません」と出る**: 選んだフォルダーのあるドライブがつながっていないか、フォルダーを消しました。つながれば、すぐに読み直します。フォルダーを消したときは、設定の「一般」の「設定の保存先」で選び直します。設定のファイルを symlink にしているときは、その先のファイルが無いときにも出ます。
::: macos
- **「〜 を読む許可がありません」と出る**: 設定のファイルを、Mawok の外のフォルダーへの symlink にしています。設定の「一般」の「設定の保存先」で「アクセスを許可...」を押し、出た窓でそのまま「開く」を押します。
:::
- **ほかのデバイスで変えた設定が届かない**: 2台で同じフォルダーを保存先に選んでいるかを、設定の「一般」の「設定の保存先」で確かめます。選んでいれば、クラウドストレージがまだ同期していません。クラウドストレージのアプリで、同期の様子を確かめます。

不具合を報告するときは、ログを添えてください。ログにテキストの中身は残していません。ログの場所は、設定の「このアプリについて」から開けます。

## 送る内容とプライバシー

- Mawok は、使われ方の統計やエラーの報告を送りません。
- Mawok は、テキストと設定を外へ送りません。保存先をクラウドストレージのフォルダーにすると、設定と履歴はそのクラウドストレージが送ります。

::: linux
## 入れ方と更新

- Ubuntu: mawok.amiiby.com の手順で Mawok の apt リポジトリを足し、`sudo apt install mawok` で入れます。更新は、ほかのアプリと一緒に「ソフトウェアの更新」か `sudo apt upgrade` で届きます。
- Arch Linux: AUR の `mawok-bin` を、AUR のヘルパー (`yay` など) で入れます。更新も、同じヘルパーで行います。
:::

## アンインストール

::: macos
1. メニューバーのメニューの「終了」で終了し、`/Applications/Mawok.app` をゴミ箱に入れます。
2. 設定と履歴も消すなら、`~/Library/Containers/com.amiiby.mawok/` を消します。設定の保存先を変えていたら、そのフォルダーの設定のファイルと `history` フォルダーも消します。
:::

::: windows
1. Windows の「設定」の「アプリ」から Mawok をアンインストールします。設定と履歴も消えます。
2. 設定の保存先を変えていたら、そのフォルダーの設定のファイルと `history` フォルダーは残ります。要らなければ消します。
:::

::: linux
1. 設定の「一般」で「ログイン時に起動」をオフにします。
2. トレイのメニューの「終了」で終了し、Ubuntu では `sudo apt remove mawok`、Arch Linux では `sudo pacman -R mawok-bin` を実行します。apt リポジトリも外すなら、mawok.amiiby.com の手順で外します。
3. 設定と履歴も消すなら、`~/.config/com.amiiby.mawok/` と `~/.local/share/com.amiiby.mawok/` を消します。設定の保存先を変えていたら、そのフォルダーの設定のファイルと `history` フォルダーも消します。
:::
