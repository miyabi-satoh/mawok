# Mawok の使い方

## はじめに

どのアプリを使っているときでも、テキストウィンドウを出して書き、コピーして元のアプリに貼り付けられます。

1. {macos:`Cmd+Shift+Space`}{windows:`Ctrl+Shift+Space`} を押して、テキストウィンドウを出します。
2. 書きます。`Enter` は改行です。
3. {macos:`Cmd+Enter`}{windows:`Ctrl+Enter`} を押すと、コピーしてテキストウィンドウが閉じ、元のアプリに戻ります。そこで貼り付けます。

ほかに、定型文を挿入したり、テキストを AI やコマンドで書き換えたりできます。
Mawok は{macos:メニューバー}{windows:タスクトレイ}に常駐し、ログイン時に起動します (設定の「一般」でオフにできます)。

## 書いてコピーする

- {macos:`Cmd+Enter`}{windows:`Ctrl+Enter`} を押すか「コピー」ボタンを押すと、コピーして元のアプリに戻ります。
- テキストウィンドウが前面にあるときにホットキーを押しても、コピーして戻ります。1行目が `@ai`・`@sh` でも、実行せずにコピーします。
- コピーせずに戻るときは `Esc` を押します。書きかけは、次にテキストウィンドウを出したときもそのまま残っています。
- ほかのアプリをクリックしたときも、コピーせずに隠れ、書きかけは残ります (設定の「一般」でオフにできます)。

## 前にコピーしたテキストを使う

コピーしたテキストは履歴に残ります。

- 入力欄の先頭で `↑` を押すと、前にコピーしたテキストが出ます。押すたびに古い方へさかのぼり、入力欄の末尾で `↓` を押すと新しい方へ戻ります。上の「前」「次」のボタンでも同じです。
- 残す件数は設定の「一般」で変えられます。0 にすると履歴を残しません。
- 履歴を同期しているときは、設定の「履歴を削除する」を押すか件数を 0 にすると、ほかのデバイスの履歴も消えます (「[設定と履歴を同期する](#設定と履歴を同期する)」を参照)。

## 定型文を使う

よく使う文や、テキストを AI やコマンドで書き換える指示を登録しておき、選んで使います。

1. {macos:`Cmd+K`}{windows:`Ctrl+K`} を押して、定型文の一覧を出します。
2. 文字を打って絞り込み、`Enter` で選びます。

- ふつうの定型文は、カーソルの位置に挿入されます。
- 1行だけで `@ai`・`@sh` から始まる定型文は、テキストをその宛先で実行します (次の「[宛先を書いて実行する](#宛先を書いて実行する)」を参照)。範囲を選んでいればその範囲が、選んでいなければ全体が対象です。結果でテキストが置き換わり、{macos:`Cmd+Z`}{windows:`Ctrl+Z`} で元に戻せます。結果の出し方 (置き換えるか、カーソルの位置に挿入するか、出さないか) は、設定の「定型文」で定型文ごとに選べます。

最初は「英訳」(`@ai`) と「行を並べ替え」(`@sh sort`) が入っています。英訳には AI サービスの設定が要ります (「[AI を使う](#ai-を使う)」を参照)。

定型文は設定の「定型文」で登録します。一覧の末尾の「テキストを定型文に登録」を選ぶと、書いているテキストをその場で登録することもできます。範囲を選んでいればその範囲を、絞り込みに文字を打っていればその文字を名前にして登録します。

## 宛先を書いて実行する

テキストの1行目に宛先を書いて {macos:`Cmd+Enter`}{windows:`Ctrl+Enter`} を押すか「実行」ボタンを押すと、コピーする代わりに実行します。2行目から下が、宛先に渡す中身です。

| 1行目 | すること |
| --- | --- |
| `@ai 指示` | AI に頼み (AI アクション)、結果でテキストを置き換える。例: `@ai 丁寧な文に直して` |
| `@sh コマンド` | コマンドを実行し、結果でテキストを置き換える。例: {macos:`@sh sort`}{windows:`@sh dir`} |

- 1行目の先頭で `@` を打つと、宛先の候補が出ます。`Tab` か `Enter` で選びます。
- `@sh` の行で、ファイルやフォルダーの名前を途中まで打って `Tab` を押すと、続きが補完されます。候補がいくつもあれば1行目の下に並び、`Tab` を押すたびに次の候補に移ります。
- 実行する前のテキストは履歴に残るので、呼び戻してやり直せます。
- コマンドには2行目から下が渡され、コマンドの出力が結果になります。{macos:}{windows:コマンドは cmd で実行されます。}
::: macos
- コマンドが見つからないときは、フルパスで書きます。
:::
::: windows
- Windows に初めから入っているコマンド (`sort`・`findstr` など) に日本語を渡すと、1行目に打って実行したときは文字が化けます。定型文に登録し、設定の「定型文」でその定型文の「文字コード」を「Shift_JIS」にして使います。最初から入っている「行を並べ替え」は、そうしてあります。
:::

コマンドはホームフォルダーで実行されます。左下のフォルダーのボタンに、今のフォルダーが出ます。別のフォルダーで実行するには、ボタンを押してフォルダーを選びます。一度移ったフォルダーは、ボタンのメニューから選び直せます。ホームフォルダーに戻るには、メニューの「ホームフォルダーに戻る」を選びます。

キーボードで移るには、{macos:`Cmd+D`}{windows:`Ctrl+D`} を押して出る欄にパスを打ち、`Enter` を押します。

- 相対パスは、今のフォルダーから見たパスになります。
- フォルダーの名前を途中まで打って `Tab` を押すと、続きが補完されます。候補がいくつもあれば欄の下に並び、`Tab` を押すたびに次の候補に移ります。`Enter` で候補を決め、もう一度 `Enter` を押すとそのフォルダーに移ります。
- 打っている間、続きが1つに決まれば薄く出ます。`→` か `Tab` で確定します。
- 移った先のフォルダーは、タイトルバーに出ます。
- 欄を空にして `Enter` を押すと、ホームフォルダーに戻ります。Mawok を終了したときも戻ります。

## AI を使う

1. 設定の「AI」の「AI サービス」で、使うサービスを選びます。
2. Mawok を選んだときは、設定の「アカウント」で「サインイン」を押し、開いたページでサインインして「このデバイスを登録する」を押します。ほかのサービスを選んだときは、そのサービスの API キーを入れます。
3. 設定の「AI」に出る、送る内容の説明を読んで「同意する」を押します。

Mawok を選ぶと API キーは要らず、使った分だけアカウントのクレジットが減ります。クレジットは、設定の「AI」の「クレジットを購入」から料金のページを開いて足せます。

OpenAI と互換のサービス (DeepSeek・OpenRouter・Ollama など) を使うときは、「AI サービス」で「OpenAI」を選び、「ベース URL」をそのサービスの API の URL に替えて、そのサービスの API キーと「モデル」を入れます。キーの要らないサービス (手元で動かす Ollama など) でも、API キーには何か入れてください。

## 設定と履歴を同期する

Pro では、同じアカウントのデバイスの間で、設定と履歴を同期できます。

1. 設定の「アカウント」から Mawok にサインインします。Pro でなければ、「Pro の料金を見る」から申し込みます。
2. 「同期のパスワードを作成」で、パスワードを2回入れて「同期を開始する」を押します。
3. ほかのデバイスでもサインインし、「同期のパスワードを入力」で同じパスワードを入れて「同期を開始する」を押します。

パスワードは、設定の「アカウント」の「同期のパスワード」で「変更」を押すと変えられます。ほかのデバイスで入れ直す必要はありません。

パスワードを忘れると、取り戻す方法はありません。「パスワードをお忘れですか？」か「同期をリセット...」を押して、新しいパスワードで始め直します。Mawok のサーバーにある同期のデータは消えますが、各デバイスのデータは残ります。ほかのデバイスでは、新しいパスワードを入れ直します。

書いたテキストの続きを別のデバイスで書くには、{macos:`Cmd+Enter`}{windows:`Ctrl+Enter`} でコピーして閉じ、別のデバイスのテキストウィンドウで `↑` を押して履歴を出します。コピーしてすぐは、まだ届いていないことがあります。少し待ってテキストウィンドウを出し直すと届きます。

- 同期するもの: 設定、キー操作、置き換え辞書、定型文、履歴。設定の「アカウント」で、種類ごとにオン・オフにできます。
- デバイスごとのもの: ログイン時の起動、AI サービスの API キー。ホットキーとキー操作は、{macos:Mac どうし}{windows:Windows どうし}で同期します。
- 設定、置き換え辞書、定型文は、雲の印をオフにすると、その項目や行だけ同期しなくなります。

同じ設定をデバイスごとに変えたときは、後から変えた方が使われます。前の設定に戻すには、バックアップから戻します (「[設定](#設定)」を参照)。

## キー操作の一覧

| 操作 | キー |
| --- | --- |
| テキストウィンドウを出す (前面にあればコピーして閉じる) | {macos:`Cmd+Shift+Space`}{windows:`Ctrl+Shift+Space`} |
| コピーして閉じる (1行目が `@ai`・`@sh` のときは実行する) | {macos:`Cmd+Enter`}{windows:`Ctrl+Enter`} |
| コピーせずに閉じる | `Esc` |
| 履歴をさかのぼる (入力欄の先頭で)・新しい方へ戻る (入力欄の末尾で) | `↑` / `↓` |
| 履歴をさかのぼる・新しい方へ戻る (カーソルの位置にかかわらず) | {macos:`Cmd+Option+↑` / `Cmd+Option+↓`}{windows:`Ctrl+Alt+↑` / `Ctrl+Alt+↓`} |
| 定型文の一覧を開く | {macos:`Cmd+K`}{windows:`Ctrl+K`} |
| フォルダーへ移動 | {macos:`Cmd+D`}{windows:`Ctrl+D`} |
| 実行を取り消す (実行している間) | `Esc` |
| 設定を開く | {macos:`Cmd+,`}{windows:`Ctrl+,`} |

キーは設定の「キー操作」で変えられます。

## 設定

{macos:メニューバー}{windows:タスクトレイ}のメニューの「設定…」を選ぶか、テキストウィンドウで {macos:`Cmd+,`}{windows:`Ctrl+,`} を押すと開きます。
ホットキー、テキストの見た目、コピーするときの整え (末尾の空白を取る・全角と半角を揃える・置き換え辞書など) を変えられます。変えた内容はすぐに反映されます。
既定の値から変えた設定には、行の左端に縦の線が付きます。

設定は毎日、自動でバックアップされます。前の設定に戻すには、設定の「このアプリについて」で「バックアップから戻す...」を押し、戻したい日時を選んで「この設定に戻す」を押します。「今すぐバックアップ」を押すと、その時点の設定を残せます。

## うまくいかないとき

- **ホットキーが効かない**: ほかのアプリが同じキーを使っています。このとき、{macos:メニューバー}{windows:タスクトレイ}のメニューに ⚠ が出ます。設定の「キー操作」で別のキーにします。
::: macos
- **「API キーを読めませんでした」と出る**: アプリを入れ直した後は、キーチェーンへのアクセスの許可を求められます。許可してください。直らなければ、設定の「AI」でキーを入れ直します。
:::
::: windows
- **「API キーを読めませんでした」と出る**: 設定の「AI」でキーを入れ直します。
:::
- **「設定を読めなかったため、〜既定の設定で始めました」と出る**: 設定の「このアプリについて」で「バックアップから戻す...」を押し、前の設定に戻します。
- **「設定を保存できません」と出る**: 変えた設定は、終了すると元に戻ります。ディスクの空きを確かめて、Mawok を起動し直します。
- **「〜につながりませんでした」「〜から時間内に応答がありませんでした」と出て、やり直しても直らない**: ネットワークにつながっているかを確かめます。つながっていれば、Mawok のサーバーか AI サービスが不調です。時間をおいてやり直します。
- **「Mawok のアカウントにクレジットがありません」と出る**: 設定の「AI」の「クレジットを購入」で足します。
- **「AI サービスの利用額かクレジットの上限に達しました」と出る**: やり直しても直りません。AI サービスのアカウントで、残高と上限を確かめます。
- **「今のフォルダーが見つかりません」と出る**: フォルダーを移したり消したりすると出ます。「フォルダーへ移動」で移り直します。
::: macos
- **「コマンドが見つかりませんでした」と出る**: コマンドをフルパスで書きます。
:::

不具合を報告するときは、ログを添えてください。ログにテキストの中身は残していません。ログの場所は、設定の「このアプリについて」から開けます。

## 送る内容とプライバシー

- Mawok は、使われ方の統計やエラーの報告を送りません。
- テキストを外へ送るのは、AI アクション (`@ai`) を実行したとき (選んだ AI サービスへ) と、Pro で同期しているときだけです。
- Pro で同期しているときは、同期するものを暗号化して Mawok のサーバーに置きます。Mawok のサーバーは、中身を読めません。
- AI サービスが送った内容をどう扱うか (学習に使うか・保持する日数) は、サービスを選んで「同意する」を押す前の画面に出ます。

## アンインストール

::: macos
1. API キーを入れていたら、設定の「AI」で、入れたサービスごとに「AI サービス」で選んで「削除する」を押します。Mawok にサインインしていたら、設定の「アカウント」で「サインアウトする」を押します。
2. メニューバーのメニューの「終了」で終了し、`/Applications/Mawok.app` をゴミ箱に入れます。
3. 設定と履歴も消すなら、`~/Library/Application Support/com.amiiby.mawok/` と `~/Library/Logs/com.amiiby.mawok/` を消します。
:::

::: windows
1. API キーを入れていたら、設定の「AI」で、入れたサービスごとに「AI サービス」で選んで「削除する」を押します。Mawok にサインインしていたら、設定の「アカウント」で「サインアウトする」を押します。
2. Windows の「設定」の「アプリ」から Mawok をアンインストールします。設定と履歴も消えます。
:::
