# Mawok の使い方

## はじめに

Mawok は、ターミナルなどに文字を送る前に、いったん書いておく場所です。
音声入力が直接入らないアプリや、IME のオンオフを間違えやすい場面で、いったん Mawok に書いてから貼り付けます。

1. {macos:`Cmd+Shift+Space`}{windows:`Ctrl+Shift+Space`} でテキストウィンドウを出す。
2. 書く。Enter は改行です。
3. {macos:`Cmd+Enter`}{windows:`Ctrl+Enter`} でコピーして閉じ、戻った先のアプリで貼り付ける。

ほかに、定型文の挿入、AI やコマンドでの書き換えができます。
Mawok は{macos:メニューバー}{windows:タスクトレイ}に常駐し、ログイン時に起動します (設定の「一般」で切れます)。

## 書いてコピーする

- {macos:`Cmd+Enter`}{windows:`Ctrl+Enter`} か「コピー」ボタンで、コピーして前のアプリに戻ります。テキストウィンドウが前面にあるときにホットキーを押しても同じです。
- コピーせずに戻るときは `Esc` を押します。書きかけは次に出したときに残っています。
- ほかのアプリをクリックしたときも、コピーせずに隠れ、書きかけは残ります (設定の「一般」で切れます)。

## 前にコピーしたテキストを使う

コピーしたテキストは履歴に残ります。

- 入力欄の先頭で `↑`、末尾で `↓` を押すと、前後の履歴が出ます。
- 件数は設定の「一般」で変えられます。0 にすると履歴を残しません。
- 履歴を同期しているときは、設定の「履歴を削除する」を押すか、件数を 0 にすると、ほかのデバイスの履歴も消えます (「設定と履歴を同期する」)。

## 定型文を使う

よく使う文や、テキストを AI やコマンドに通す指示を登録しておき、選んで使います。

1. {macos:`Cmd+K`}{windows:`Ctrl+K`} で定型文の一覧を出す。
2. 文字を打って絞り込み、Enter で選ぶ。

- ふつうの定型文は、カーソルの位置に挿入されます。
- 1行だけで `@ai`・`@sh` から始まる定型文は、テキストをその宛先へ出します (次の「宛先を書いて出す」)。範囲を選んでいればその範囲、なければ全体が対象です。結果は入力欄に入り、{macos:`Cmd+Z`}{windows:`Ctrl+Z`} で元に戻せます。

最初は「英訳」(`@ai`) と「行を並べ替え」(`@sh sort`) が入っています。英訳には AI サービスの設定が要ります (「AI を使う」)。

定型文は設定の「定型文」で登録します。一覧の末尾の「テキストを定型文に登録」で、書いているテキストをその場で登録することもできます。

## 宛先を書いて出す

テキストの1行目に宛先を書き、{macos:`Cmd+Enter`}{windows:`Ctrl+Enter`} か「実行」ボタンで出します。1行目が宛先のときは、コピーの代わりに実行します。2行目から下が、宛先に渡す中身です。

| 1行目 | すること |
| --- | --- |
| `@ai 指示` | AI に頼み (AI アクション)、結果でテキストを置き換える。例: `@ai 丁寧な文に直して` |
| `@sh コマンド` | コマンドを実行し、結果でテキストを置き換える。例: `@sh sort` |

- 1行目の先頭で `@` を打つと、宛先の候補が出ます。`Tab` か `Enter` で入れます。
- 出したテキストは履歴に残るので、呼び戻して直せます。
- コマンドには、2行目から下を標準入力で渡し、標準出力を結果にします。{macos:}{windows:Windows では cmd で動きます。}
::: macos
- コマンドが見つからないときは、フルパスで書きます。
:::

コマンドはホームフォルダーで動きます。左下のフォルダーのボタンに、今のフォルダーが出ます。別のフォルダーで動かすには、ボタンを押してフォルダーを選びます。一度移ったフォルダーは、ボタンのメニューから選び直せます。メニューの「ホームフォルダーに戻る」で戻ります。

キーボードでは、{macos:`Cmd+D`}{windows:`Ctrl+D`} で出る欄にパスを打って `Enter` を押します。

- 相対パスは、今のフォルダーから見たパスになります。
- フォルダーの名前を途中まで打って `Tab` を押すと、続きを補います。候補が複数あれば欄の下に出て、もう一度 `Tab` を押すと順に選べます。`Enter` で選んだフォルダーに決め、もう一度 `Enter` で移ります。
- 打っている間、続きが1つに決まれば薄く出ます。`→` か `Tab` で受け入れます。
- 移った先はタイトルバーに出ます。
- 欄を空にして `Enter` を押すとホームフォルダーに戻ります。Mawok を終了したときも戻ります。

## AI を使う

1. 設定の「AI」の「AI サービス」で、使うサービスを選ぶ。
2. Mawok を選んだら、設定の「アカウント」で「サインイン」を押し、開いたページでサインインして「このデバイスを登録する」を押す。ほかのサービスなら API キーを入れる。
3. 設定の「AI」で、送る内容の説明を読んで「同意する」を押す。

Mawok を選ぶと API キーは要らず、使った分だけアカウントのクレジットから減ります。クレジットは設定の「AI」の「クレジットを購入」から料金ページを開いて足せます。

## 設定と履歴を同期する

Pro では、同じアカウントのデバイスの間で、設定と履歴が同じになります。

1. 設定の「アカウント」から Mawok にサインインします。
2. 「同期のパスワードを作成」で、パスワードを2回入れて「同期を開始する」を押します。
3. ほかのデバイスでもサインインし、「同期のパスワードを入力」で同じパスワードを入れて「同期を開始する」を押します。

パスワードは、設定の「アカウント」の「同期のパスワード」で「変更」を押して変えられます。ほかのデバイスで入れ直す必要はありません。

パスワードを忘れた場合は復元できません。「パスワードをお忘れですか？」か「同期をリセット...」から、新しいパスワードで始め直します。Mawok のサーバーにある同期データは消えますが、各デバイスのデータは残ります。ほかのデバイスでは、新しいパスワードを入れ直します。

書いたテキストの続きを別のデバイスで使うには、{macos:`Cmd+Enter`}{windows:`Ctrl+Enter`} でコピーして閉じ、別のデバイスのテキストウィンドウで `↑` を押して履歴を出します。コピーしてすぐは、まだ届いていないことがあります。少しおいてテキストウィンドウを出し直すと、届きます。

- 同期するもの: 設定、キー操作、置き換え辞書、定型文、履歴。設定の「アカウント」で、種類ごとにオン・オフにできます。
- デバイスごとのもの: ログイン時の起動、AI サービスの API キー。ホットキーとキー操作は、{macos:Mac どうし}{windows:Windows どうし}で同期します。
- 設定、置き換え辞書、定型文は、雲の印をオフにすると、その項目や行だけ同期しなくなります。同期を止めるには、その種類をオフにします。

同じ設定を別々のデバイスで変更すると、設定の「アカウント」に「どちらを使うか選ぶ...」が出ます。押して、項目ごとに「このデバイス」か「ほかのデバイス」を選び、「選んだ設定を適用する」を押します。{macos:メニューバー}{windows:タスクトレイ}のメニューの「どちらの設定を使うか選ぶ…」からも開けます。

同期で設定が変わった後に前の状態へ戻したいときは、設定の「アカウント」で「同期の前の設定に戻す...」を押します。戻したい日時の設定を選び、「この設定に戻す」を押します。

## キー操作の一覧

| 操作 | キー |
| --- | --- |
| テキストウィンドウを出す (前面にあればコピーして閉じる) | {macos:`Cmd+Shift+Space`}{windows:`Ctrl+Shift+Space`} |
| コピーして閉じる (1行目が `@ai`・`@sh` のときは実行) | {macos:`Cmd+Enter`}{windows:`Ctrl+Enter`} |
| コピーせずに閉じる | `Esc` |
| 前にコピーしたテキストを出す (入力欄の先頭で ↑、末尾で ↓) | `↑` / `↓` |
| 前の履歴・次の履歴 (カーソルの行にかかわらず) | {macos:`Cmd+Option+↑` / `Cmd+Option+↓`}{windows:`Ctrl+Alt+↑` / `Ctrl+Alt+↓`} |
| 定型文の一覧を開く | {macos:`Cmd+K`}{windows:`Ctrl+K`} |
| フォルダーへ移動 | {macos:`Cmd+D`}{windows:`Ctrl+D`} |
| 実行を取り消す (実行している間) | `Esc` |
| 設定を開く | {macos:`Cmd+,`}{windows:`Ctrl+,`} |

キーは設定の「キー操作」で変えられます。

## 設定

{macos:メニューバー}{windows:タスクトレイ}のメニューの「設定…」か、テキストウィンドウで {macos:`Cmd+,`}{windows:`Ctrl+,`} を押すと開きます。
ホットキー、テキストの見た目、コピーするときの整え (末尾の空白を取る・全角と半角を揃える・置き換え辞書など) を変えられます。変えた内容はすぐに効きます。
既定の値から変えた設定には、行の左端に縦の線が付きます。

## うまくいかないとき

- **ホットキーが効かない**: ほかのアプリと同じキーになっています。{macos:メニューバー}{windows:タスクトレイ}のメニューに ⚠ が出ます。設定の「キー操作」で別のキーにします。
::: macos
- **「API キーを読めませんでした」と出る**: アプリを入れ直した後は、キーチェーンへのアクセスの許可を求められます。許可してください。直らなければ、設定の「AI」でキーを入れ直します。
:::
::: windows
- **「API キーを読めませんでした」と出る**: 設定の「AI」でキーを入れ直します。
:::
- **「〜につながりませんでした」「〜読み込めませんでした」などと出て、やり直しても直らない**: ネットワークにつながっているかを確かめます。つながっていれば、Mawok のサーバーか AI サービスの不調です。時間をおいてやり直します。
- **「AI サービスの利用額かクレジットの上限に達しました」と出る**: やり直しても直りません。AI サービスのアカウントで、残高と上限を確かめます。
- **「今のフォルダーが見つかりません」と出る**: フォルダーを移したか消したときに出ます。「フォルダーへ移動」で移り直します。
::: macos
- **「コマンドが見つかりませんでした」と出る**: コマンドをフルパスで書きます。
:::

不具合を報告するときは、ログを添えてください。テキストの内容は残していません。ログの場所は、設定の「このアプリについて」から開けます。

## 送る内容とプライバシー

- Mawok は、使われ方の統計やエラーの報告を送りません。
- テキストを外へ送るのは、AI アクション (`@ai`) を実行したとき (選んだ AI サービスへ) と、Pro で同期しているときだけです。
- Pro で同期しているときは、同期するものを暗号化して Mawok のサーバーに置きます。Mawok のサーバーは、中身を読めません。
- AI サービスが送った内容をどう扱うか (学習に使うか・保持する日数) は、サービスを選んで「同意する」を押す前の画面に出ます。

## 設定ファイル

設定は `config.toml` に保存されます。場所は、設定の「このアプリについて」から開けます。
手で書き換えたときは、アプリを再起動すると効きます。ファイルには既定と違う値だけが書かれます。

| 項目                             | 既定値                           | 内容                                                                     |
| -------------------------------- | -------------------------------- | ------------------------------------------------------------------------ |
| `hotkey`                         | `"CommandOrControl+Shift+Space"` | テキストウィンドウを出すホットキー。空にすると使わない                   |
| `autostart`                      | `true`                           | ログイン時に起動する                                                     |
| `sync_settings`                  | `true`                           | Pro で、設定をほかのデバイスと同期する                                   |
| `sync_keys`                      | `true`                           | Pro で、キー操作をほかのデバイスと同期する                               |
| `sync_replacements`              | `true`                           | Pro で、置き換え辞書をほかのデバイスと同期する                           |
| `sync_snippets`                  | `true`                           | Pro で、定型文をほかのデバイスと同期する                                 |
| `sync_history`                   | `true`                           | Pro で、履歴をほかのデバイスと同期する                                   |
| `sync_excluded_settings`         | `[]`                             | 設定の同期から外す設定ファイルの項目名                                   |
| `language`                       | `"system"`                       | 表示言語 (`"system"`・`"ja"`・`"en"`)                                   |
| `theme`                          | `"system"`                       | テーマ (`"system"`・`"light"`・`"dark"`)                                |
| `text_window_always_on_top`      | `true`                           | テキストウィンドウを常に最前面に表示する                                 |
| `hide_text_window_on_blur`       | `true`                           | ほかのアプリに移ったらテキストウィンドウを隠す                           |
| `show_text_window_buttons`       | `true`                           | テキストウィンドウにボタンを表示する                                     |
| `text_history_size`              | `50`                             | 履歴の件数 (0〜100)                                                     |
| `trim_trailing_whitespace`       | `true`                           | コピーするときに末尾の空白文字を取り除く                                 |
| `punctuation_style`              | `"keep"`                         | 句読点を揃える (`"keep"`・`"kutouten"`・`"comma"`)                      |
| `alphabet_width`                 | `"keep"`                         | 英字の全角・半角を揃える (`"keep"`・`"full"`・`"half"`)                 |
| `digit_width`                    | `"keep"`                         | 数字の全角・半角を揃える (`"keep"`・`"full"`・`"half"`)                 |
| `space_width`                    | `"keep"`                         | 空白の全角・半角を揃える (`"keep"`・`"full"`・`"half"`)                 |
| `symbol_width`                   | `"keep"`                         | 記号の全角・半角を揃える (`"keep"`・`"full"`・`"half"`)                 |
| `katakana_width`                 | `"keep"`                         | 半角カナを全角にする (`"keep"`・`"full"`)                               |
| `exclude_from_clipboard_history` | `true`                           | クリップボードの履歴に残さない                                           |
| `text_font_family`               | `""`                             | テキストのフォント (CSS の font-family。空なら OS 標準)                 |
| `text_font_size`                 | `16`                             | テキストの文字の大きさ (10〜32)                                         |
| `text_color_light`               | `""`                             | テキストの文字色 (ライト。`#rrggbb`。空なら標準)                        |
| `text_color_dark`                | `""`                             | テキストの文字色 (ダーク。`#rrggbb`。空なら標準)                        |
| `input_guidance`                 | なし                             | 入力欄の案内。書かなければ既定の案内、空文字なら出さない                 |
| `[text_window_keys]`             | 「キー操作の一覧」の既定のキー   | テキストウィンドウのキー。`copy`・`history_older` など操作ごと。空文字は割り当てなし |
| `[[replacements]]`               | なし                             | 置き換え辞書の1件 (`from`・`to`・`enabled`)                             |
| `[[snippets]]`                   | 表示言語の既定の定型文           | 定型文の1件 (`name`・`body`・`output`〔`"replace"`・`"insert"`・`"none"`〕・`encoding`〔`"utf-8"`・`"shift_jis"` など〕・`enabled`) |
| `ai_service`                     | `"none"`                         | AI アクション (`@ai`) に使う AI サービス (`"none"`・`"mawok"`・`"gemini"`・`"anthropic"`・`"openai"`) |
| `ai_consent`                     | なし                             | 送る内容と扱いに同意した AI サービス                                     |
| `[ai_models]`                    | AI サービスごとの既定のモデル    | AI のモデル。AI サービスごと (`gemini = "…"`・`anthropic = "…"` など)   |

## アンインストール

::: macos
1. 設定の「AI」で API キーを入れていたら「削除する」、設定の「アカウント」で Mawok にサインインしていたら「サインアウトする」を押しておく。
2. メニューバーのメニューの「終了」で終了し、`/Applications/Mawok.app` をゴミ箱に入れる。
3. 設定と履歴も消すなら、`~/Library/Application Support/com.amiiby.mawok/` と `~/Library/Logs/com.amiiby.mawok/` を消す。
:::

::: windows
1. 設定の「AI」で API キーを入れていたら「削除する」、設定の「アカウント」で Mawok にサインインしていたら「サインアウトする」を押しておく。
2. Windows の「設定」の「アプリ」から Mawok をアンインストールする。Microsoft Store 版は、設定と履歴も消える。
:::
